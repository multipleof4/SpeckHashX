SpeckHashX

A hash function with any output length, built from the Speck cipher.

Hashed in your browser. Nothing you type leaves this page.
  • Any length. Ask for 1 byte or 1,000. Each length gives its own unrelated hash.
  • Same answer everywhere. One source runs in Rust, Node, Bun and browsers.
  • Public domain. CC0, the same terms as Speck itself.
